How to use this interactive

The idea

  • The blue curve shows where an object is at each moment. Its steepness is how fast the object is moving.
  • The orange secant joins two moments, t and t + Δt. Its slope is the average velocity over that gap.
  • As you shrink Δt, the secant swings onto the green tangent. Its slope is the instantaneous velocity at t — the limit of Δx/Δt as Δt → 0.

Try this

  1. Press Play and watch the orange point slide toward the blue one. Watch the "Average velocity" number settle.
  2. Press Start over, then use Halve Δt one step at a time. Before each press, predict the next value of Δx/Δt.
  3. Move Choose the instant t. Does the limit change? Compare it with 2t (for x = t²) or 3t² (for x = t³).
  4. Switch to t² + 10. The curve moves up but the velocity stays the same. Why?

For teachers

  • Best projected with the table visible: each halving adds a row, so the class can see Δx/Δt closing in on the limit.
  • Ask: "Why does Δx/Δt never quite equal 2 — and why do we still say the velocity is 2?"
